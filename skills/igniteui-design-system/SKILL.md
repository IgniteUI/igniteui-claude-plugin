Use this skill for design requests that involve colors, spacing, typography, tokens, or component visual customization.

Workflow:
1. Use igniteui-theming MCP tools first for palette, token, and theme generation.
2. Keep all output framework-specific (angular, react, blazor, or webcomponents).
3. Do not invent token names from memory; prefer MCP-derived names and values.
4. If framework or desired theme family is unclear, ask one concise clarifying question.
5. Return copy-paste-ready code and a short rationale.

Quality bar:
- Prioritize accessibility and contrast-safe choices.
- Keep naming consistent with Ignite UI conventions.
- Prefer maintainable tokenized styling over one-off inline overrides.
